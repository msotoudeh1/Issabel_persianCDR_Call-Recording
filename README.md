# سامانه مانیتورینگ، آنالیز و شنود مکالمات ایزابل (Issabel Persian CDR)

یک پنل اختصاصی، مدرن و کاملاً فارسی برای تحلیل تماس‌ها، گزارش‌گیری پیشرفته و شنود فایل‌های صوتی در سیستم‌های تلفنی ایزابل (Issabel PBX).

---

## 🚀 ویژگی‌های کلیدی نسخه جدید

- 🔒 **سامانه احراز هویت و امنیت ورود:** صفحه لاگین مدرن و ایمن با امکان تعیین نام کاربری و کلمه عبور دلخواه به همراه کنترل سشن و ضد بروت‌فورس.
- ⚙️ **مدیریت حساب و تغییر رمز عبور از داخل پنل:** تغییر نام کاربری و پسورد به صورت آنی از طریق پاپ‌آپ هدر یا صفحه اختصاصی تنظیمات (`settings.php`) با هش رمز عبور `bcrypt`.
- 🎙️ **بخش اختصاصی صندوق صوتی (ویس‌میل - Voicemail):** اسکن خودکار ویس‌میل‌های ایزابل، مرتب‌سازی پیشرفته (جدیدترین، قدیمی‌ترین، طولانی‌ترین و کوتاه‌ترین پیام‌ها)، شنود آنلاین و دانلود فایل صوتی.
- 🎨 **طراحی لوکس و مدرن (Glassmorphism):** رابط کاربری شیشه‌ای مبتنی بر Tailwind CSS و هدر دو سطحی کاملاً بالانس و متقارن.
- 🔢 **ارقام و اعداد استاندارد لاتین (0-9):** نمایش شفاف و بدون تداخل اعداد در تمامی جداول، کارت‌های آماری، نمودارها و ساعت سیستم.
- 🌓 **پشتیبانی کامل از تم تیره و روشن (Dark / Light Mode):** هماهنگی اتوماتیک با سیستم‌عامل و کلید سوئیچ فوری در هدر.
- ⚡ **دکمه‌های فیلتر سریع بازه زمانی:** انتخاب آسان «امروز»، «دیروز»، «7 روز اخیر»، «30 روز اخیر» یا «تمام زمان‌ها» بدون نیاز به تایپ دستی تاریخ.
- 🎵 **پلیر اختصاصی پخش مکالمات:** پخش، عقب و جلو بردن صوت، نمایش ثانیه‌شمار و دانلود مستقیم بدون به‌هم‌ریختگی ظاهری مرورگر.
- 📊 **تحلیل هوشمند و شاخص‌های کلیدی (KPIs):** نرخ پاسخ‌دهی، میانگین زمان انتظار، میانگین مکالمه، شلوغ‌ترین ساعت روز و رتبه‌بندی اپراتورها با مدال‌های افتخار.
- 📑 **خروجی اکسل استاندارد (CSV):** با پشتیبانی کامل از UTF-8 BOM جهت نمایش بدون نقص حروف فارسی در نرم‌افزار Excel.

## 🛠️ راهنمای نصب و راه‌اندازی

### ۱. انتقال فایل‌ها به سرور ایزابل
محتویات پوشه `html` را به مسیر وب‌سرور آپاچی ایزابل منتقل کنید:
```bash
cp -r html/* /var/www/html/
```

### ۲. تنظیمات پایگاه داده و حساب کاربری
فایل `config.php` موجود در مسیر `/var/www/html/record/config.php` را باز کرده و اطلاعات دیتابیس و کلمه عبور ورود را تنظیم کنید:

```php
return [
    'db_host'        => '127.0.0.1',
    'db_name'        => 'asteriskcdrdb',
    'db_user'        => 'asteriskuser',
    'db_pass'        => 'database_password', // پسورد دیتابیس استریسک

    'auth_enabled'   => true,               // فعال بودن لاگین
    'admin_username' => 'admin',            // نام کاربری ورود به پنل
    'admin_password' => 'admin@123',        // کلمه عبور ورود به پنل (حتماً تغییر دهید)
];
```

> **نکته امنیتی:** نام کاربری پیش‌فرض `admin` و رمز عبور پیش‌فرض `admin@123` است. توصیه می‌شود پس از نصب حتماً رمز عبور را در فایل `config.php` تغییر دهید.

### ۳. مجوز دسترسی به فایل‌های ضبط صوت
در صورتی که فایل‌های مکالمات در پنل قابل پخش یا دانلود نبودند، مالکیت و دسترسی پوشه مانیتور استریسک را تنظیم کنید:
```bash
chown -R asterisk:asterisk /var/spool/asterisk/monitor/
chmod -R 755 /var/spool/asterisk/monitor/
```

## 🌐 نحوه دسترسی به پنل

در مرورگر خود آدرس زیر را وارد نمایید:
```text
https://<Issabel_IP>/record/monitoring.php
```
پس از باز شدن، به صورت خودکار به صفحه ورود هدایت خواهید شد.
